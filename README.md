# ιστοσελίδες. — istoselides.ai

Σελίδα πωλήσεων για το προϊόν «site για μικρή επιχείρηση, 400€ + ΦΠΑ, έτοιμο σε 5 μέρες»,
sub-brand του thefixer. Στατικό, χωρίς build, Netlify.

- `index.html` — η σελίδα · `efcharisto/` — μετά τη φόρμα · `aporrito/` — απόρρητο
- `assets/js/gl.js` — υγρή σφαίρα από κοράλι, raw WebGL raymarching
- `assets/js/app.js` — title card, grain, ring, pinned deck, reveals, form
- `assets/fonts/` — Geologica + Manrope self-hosted (με ελληνικά subsets)
- Φόρμα: Netlify Forms (`istoselides-lead`), redirect στο `/efcharisto/`
- Robots: `noindex` μέχρι το launch — ΑΦΑΙΡΕΣΕ το meta robots όταν πάει στο domain.

Brand: `~/Downloads/fixer-sites-offer/BRAND-BOARD-v1.png` · αποφάσεις: `ΑΠΟΦΑΣΕΙΣ.md` στον ίδιο φάκελο.
